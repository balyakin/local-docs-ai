# 6. Окно вместо командной строки

Ядро уже работает в терминале. `app.py` добавляет тонкий слой для браузера: кнопку обновления индекса, поле вопроса, ответ и раскрывающиеся исходные фрагменты. Логика чтения и поиска осталась в `docqa.py`; её не пришлось писать второй раз.

Создайте окружение, если не сделали этого в быстром запуске:

```bash
python -m venv .venv
```

На macOS/Linux активируйте его командой `source .venv/bin/activate`; в PowerShell — `.venv\Scripts\Activate.ps1`. Дальше:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Скопируйте свой `.md` или `.txt` файл в `documents/`. В браузере нажмите «Обновить индекс» и задайте вопрос. Потом измените в файле одну фразу и спросите снова. Приложение должно попросить пересобрать индекс — старый ответ здесь больше не подходит.

**Попробуйте сами.** Дайте человеку, который не видел код, открыть страницу и найти ответ по вашему файлу. Смотрите, где он запинается: на установке модели, кнопке обновления, формулировке вопроса или проверке источника. Запишите точный шаг. Это готовая задача для улучшения инструкции.

**Проверка:** страница показывает ответ и раскрываемые фрагменты. После изменения файла появляется просьба обновить индекс. Остановить сервер можно сочетанием `Ctrl+C` в терминале.
