# 3. Превратить папку в индекс

Поиск по точному совпадению слов легко промахивается. В документе написано «получить велосипед», а человек спрашивает «когда забрать заказ». Модель `embeddinggemma` превращает обе фразы в векторы — наборы чисел, между которыми можно измерить близость.

В `embed_texts()` приложение отправляет текст на локальный `/api/embed`. Фрагменты уходят партиями по 16. Параметр `truncate: false` сделан намеренно: если кусок не помещается в модель, лучше получить ошибку и поправить разбиение, чем тихо потерять конец текста.

Команда ниже создаст `data/index.json`:

```bash
python docqa.py index
```

Откройте файл индекса. Там лежат фрагменты, их пути, строки и числовые векторы. Файл может выглядеть тяжёлым — человеку его читать не нужно. Приложение хранит его локально и исключает из Git. При повторной команде индекс собирается заново; запись через временный файл защищает прежнюю версию, если сборка оборвётся до сохранения.

**Попробуйте сами.** Замените в одном документе слово, не меняя число букв. Затем выполните:

```bash
python docqa.py search "Когда можно забрать заказ?"
```

Программа остановится и попросит обновить индекс. Снова выполните `python docqa.py index`, а потом повторите поиск. Отпечаток из предыдущей главы нужен как раз для этой проверки.

**Проверка:** после сборки есть `data/index.json`; после изменения документов старый индекс не принимается. Исходные файлы при этом не переписываются.
