# 1. Сначала — живой ответ

Начнём с конца. После загрузки моделей программа должна ответить на вопрос по файлу, который уже лежит в `documents/`. Тогда разговор про векторы будет опираться на что-то работающее.

Установите Ollama по [инструкции для своей системы](../docs/ollama.md). Затем скачайте модели:

```bash
ollama pull embeddinggemma
ollama pull qwen3:1.7b
python docqa.py doctor
```

`embeddinggemma` превращает фрагменты текста в числа для поиска. `qwen3:1.7b` пишет ответ. Это две разные задачи; одна модель здесь не притворяется другой. Команда `doctor` проверяет и соединение, и наличие обеих моделей. Если она жалуется, исправьте указанную причину и повторите команду.

Теперь запустите первый полный круг:

```bash
python docqa.py index
python docqa.py ask "Сколько стоит диагностика?"
```

В ответе должны появиться **500 рублей** и фрагмент из `example.md`. Модель может сформулировать фразу по-своему. Найденный кусок файла — проверка, не украшение.

**Попробуйте сами.** Спросите, где находится мастерская. Адреса в примере нет. Если модель всё же назвала улицу, вы уже нашли первый случай для проверки качества: запишите вопрос и ответ, вернёмся к нему в главе 7.

**Перед следующим шагом:** `doctor` сообщает о двух моделях, `index` создал фрагменты, `ask` показал ответ и источник. Если вы пользуетесь Windows и команда `python` не находится, попробуйте `py`.
