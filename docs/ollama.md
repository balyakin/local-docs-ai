# Установить Ollama и не застрять на первом шаге

Ollama запускает модели на вашем компьютере. Наше приложение обращается к ней по адресу `http://127.0.0.1:11434`. Сначала установите Ollama, затем скачайте две модели: одна ищет близкие по смыслу фрагменты, другая формулирует ответ.

## Windows

1. Скачайте установщик с [официальной страницы Ollama](https://ollama.com/download/windows) и запустите его. По [документации Ollama для Windows](https://docs.ollama.com/windows) нужен Windows 10 22H2 или новее.
2. Откройте Ollama через меню «Пуск». Она будет работать в фоне.
3. Откройте **новое** окно PowerShell и проверьте команду `ollama --version`. Если система не находит её, закройте и вновь откройте PowerShell после установки.

## macOS

1. Скачайте `.dmg` с [официальной страницы](https://ollama.com/download/mac), перенесите Ollama в «Программы» и откройте её. Согласно [документации](https://docs.ollama.com/macos), нужна macOS 14 или новее.
2. Откройте новое окно Terminal. Проверьте `ollama --version`. При первом запуске Ollama может предложить добавить команду в `PATH` — подтвердите это в окне приложения.

## Linux

На [странице установки Ollama](https://docs.ollama.com/linux) дана такая команда:

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

После установки проверьте `ollama --version`. Если Ollama не запустилась как служба, откройте отдельный терминал и выполните `ollama serve`. Оставьте этот терминал открытым, пока пользуетесь приложением.

## Две модели

В PowerShell или терминале, независимо от системы:

```bash
ollama pull embeddinggemma
ollama pull qwen3:1.7b
```

По [каталогу Ollama](https://ollama.com/library/embeddinggemma) первая загрузка занимает около 622 МБ, [вторая](https://ollama.com/library/qwen3) — около 1,4 ГБ. Для работы понадобится больше места и памяти, чем размер файлов загрузки; на процессоре ответы могут идти медленно. Если позже захотите попробовать более крупную `qwen3:4b`, скачайте её командой `ollama pull qwen3:4b` и замените значение `CHAT_MODEL` в `docqa.py`. Для первого запуска оставьте модель из команд выше.

Вернитесь в папку проекта и выполните:

```bash
python docqa.py doctor
```

Нужен ответ о том, что Ollama работает и обе модели на месте. Если вместо него появилась ошибка, прочитайте её: `doctor` показывает команду для недостающей модели или просит запустить Ollama.

Если Ollama не принимает `embeddinggemma`, обновите саму Ollama. В [карточке модели](https://ollama.com/library/embeddinggemma) указана минимальная версия 0.11.10.

Здесь [описан API чата](https://docs.ollama.com/api/chat), а здесь — [получение векторов текста](https://docs.ollama.com/api/embed). К ним обращается `docqa.py`. Отдельную библиотеку Ollama для Python устанавливать не требуется.
