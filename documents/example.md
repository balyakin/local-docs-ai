# Веломастерская «Поворот»

Это вымышленная мастерская. Документ нужен только для первого запуска приложения.

## Часы работы

Мастерская открыта со вторника по субботу, с 10:00 до 19:00. В воскресенье и понедельник она закрыта.

## Ремонт

Диагностика стоит 500 рублей. Если клиент соглашается на ремонт, эту сумму вычитают из стоимости работы. Обычно велосипед готов через три рабочих дня после согласования.

## Выдача

Готовый велосипед можно забрать в часы работы мастерской. Для получения нужен номер заказа; бумажная квитанция не обязательна.
